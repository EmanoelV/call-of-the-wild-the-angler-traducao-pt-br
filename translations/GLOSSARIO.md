# Glossário PT-BR — The Angler

Use SEMPRE estes termos. Português do Brasil, tom natural de jogo.

## Equipamento e pesca
rod = vara | reel = molinete (baitcasting reel = carretilha; spinning reel = molinete; fly reel = carretilha de fly)
line = linha | leader = líder | hook = anzol | sinker = chumbada | float/bobber = boia | swivel = girador
lure = isca artificial | bait = isca | live bait = isca viva | soft plastic = isca de silicone | jig head = jig head
spinner = spinner | spoon = colher | crankbait = crankbait | fly (pesca) = mosca | fly fishing = pesca com mosca (fly)
tackle = equipamento de pesca | gear = equipamento | rig / rod setup = montagem
cast / casting = arremesso / arremessar | reel in / reeling = recolher / recolhimento
strike = fisgada | hook set = ferrar | bite = beliscada / mordida | catch (substantivo) = captura | catch (verbo) = pegar / capturar
drag = fricção | line tension = tensão da linha | snap (linha) = arrebentar
twitching = twitching | jigging = jigging | trolling = corrico
release (soltar peixe) = soltar | keep (peixe) = guardar | keepnet = viveiro
depth = profundidade | spot = ponto | bait spot = ponto de isca | hotspot = ponto quente
